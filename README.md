# AI 教学助手

Windows 桌面 AI 对话助手，以悬浮球形式常驻桌面，支持与任意 OpenAI 兼容接口进行流式对话，
内置高中 13 门学科的专属提示词与开场白，并可按课程表自动切换学科。

## 快速启动

已注册为系统服务，重启后会自动运行

## 使用方式

| 操作 | 效果 |
|------|------|
| 单击悬浮球 | 展开/收起卫星菜单 |
| 双击悬浮球 | 直接打开 AI 对话窗口 |
| 右键悬浮球 | 设置、退出 |
| 右下角缩放 | 鼠标拖动窗口边缘可调整大小 |

## 对话界面按钮

| 按钮 | 功能 |
|------|------|
| 📎 | 上传文件（txt/pdf/docx/图片等） |
| 🎙️ | 语音输入（点击进入连续语音模式，再次点击关闭） |
| 🔇 / 🔉 | 语音播报开关（关闭/开启，开启后 AI 回复自动朗读） |
| 💬 | 开场白引导问题（点击展开/折叠，内容随当前学科变化） |
| 清空 | 清空当前对话 |
| 发送 | 发送消息（Enter 快捷键） |

## 设置页签

右键悬浮球 → **设置**，共 7 个页签：

1. **AI 接口**：Base URL、API Key、模型（含检测模型按钮，可从 API 自动获取）、Temperature、Max Tokens
2. **预设网址**：自定义 3~6 个快捷网址
3. **百度语音识别**：API Key、Secret Key、识别模型 PID、音频格式、采样率、静音阈值、静音等待时间等
4. **语音合成**：edge-tts（联网，默认）/ 百度云端切换，含「检测当前引擎」
5. **开场白引导**：按学科管理引导问题列表（添加/编辑/删除/排序/恢复默认）
6. **系统提示词**：按学科管理系统提示词
7. **课程表**：导入/导出课程表、下载模板、启用自动切换并设置提前分钟数

> 第 5、6 两个页签共用同一个「当前激活学科」：在任意一页选择学科，另一页会同步跟着切换，
> 保证编辑的内容和实际生效的系统提示词、开场白指向同一门学科（没导入课程表时也一样）。

配置保存在 `config/settings.json`。

## 功能

- **流式 AI 对话**：实时生成回复，支持 Markdown 渲染
- **13 门学科提示词**：语文、外语、数学、物理、化学、生物、地理、历史、政治、
  信息科技、人工智能通识、音乐、美术，外加一个不绑定学科的「通用」；
  提示词采用苏格拉底式引导，每次回答控制在 350 字以内，引导学生自己思考
- **课程表自动切换**：导入课程表后，程序在每节课开始前 3 分钟自动切换到对应学科，
  并清空对话、更换开场白，让助手跟着课堂节奏走；体育、自习等无固定学科的课
  会切到通用模式，而不是沿用上一节课的学科
- **专属开场白**：每门学科各自一组引导问题，切换学科时浮层内容随之更换
- **连续语音输入**：点击麦克风后持续监听，VAD 自动检测说话结束，AI 回复后自动开始下一轮
- **语音播报**：开启后 AI 回复自动朗读（edge-tts 或百度云端，可选音色、语速、音调）
- **模型检测**：填写 Base URL 后一键检测可用模型列表
- **文件上传**：文本直读，二进制文件 base64 编码后发送，支持大文件超时自适应
- **预设网址快捷跳转**：内置浏览器或系统浏览器打开
- **系统托盘常驻**：随时唤醒

## 课程表怎么用

1. 设置 → **课程表** → 点「下载课程表模板…」保存一个 xlsx 文件
2. 用 Excel 打开，按下拉菜单填写：
   - **星期**：从下拉菜单选择（周一 ~ 周日）
   - **开始时间 / 结束时间**：手工输入，格式统一为 `HH:MM`（如 `08:00`、`14:35`）
   - **学科**：从下拉菜单选择标准学科名
3. 保存后回到设置 → 点「导入课程表…」选择该文件
4. 勾选「启用课程表自动切换学科」，设定提前分钟数（默认 3 分钟），保存

程序会在每节课开始前若干分钟自动切换学科，并在对话面板提示。
课程表里写「英语」「日语」「俄语」「西班牙语」会自动归到「外语」，
「信息技术」会归到「信息科技」，「AI」会归到「人工智能通识」。

**体育、自习这类没有固定学科的课**：直接把课程名填进去（或者是下拉菜单里的
「通用」「体育」「自习」「班会」「升旗」「课间操」）即可。这些时段助手会切到
**通用模式**——不再沿用上一节课的学科，改用一段跨学科的通用提示词和一组通用
开场白，面板上会注明当前上的是什么课（如「AI 助手 · 体育」）。自习课上学生问
哪一科都能得到回答。

## 系统要求

- Windows 10/11
- Python 3.9+

## 依赖

- PyQt5>=5.15.9（必需）
- PyQtWebEngine>=5.15.6（可选，未安装时使用系统默认浏览器）
- httpx>=0.25.0（HTTP 客户端）
- markdown>=3.5（Markdown 渲染）
- pyaudio（语音录音）
- pywin32>=306（Windows API）
- openpyxl>=3.1（课程表导入/导出）
- edge-tts>=7.2（联网语音合成）
